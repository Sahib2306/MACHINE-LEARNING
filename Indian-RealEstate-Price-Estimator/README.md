# 🏡 India Housing Price Prediction using Linear Regression

This project predicts **housing prices in India** (in Lakhs) using a Linear Regression model.  
The dataset includes features such as Property Type, Location, Bathroom count, Size (Sq.Ft), and more.

The notebook performs **data preprocessing, cleaning, visualization, encoding, scaling, model building, and evaluation**.

---


---

## 📊 Features of the Project

### ✔ Dataset Processing
- Handling missing values  
- Removing duplicates  
- Treating outliers  
- Selecting target variable: **Price_in_Lakhs**  

### ✔ Exploratory Data Analysis (EDA)
- Distribution plots  
- Correlation heatmaps  
- Checking skewness & transformations  

### ✔ Data Preprocessing
- Label Encoding  
- One-Hot Encoding  
- Standard Scaling via `StandardScaler`  

### ✔ Model Building
- Train-Test Split  
- Linear Regression model  
- Prediction & residual analysis  

### ✔ Model Evaluation
Metrics used:
- **MAE**  
- **MSE / RMSE**  
- **R² Score**
